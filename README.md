# GridZakon

Сайт Алексея Гридасова. Статический HTML/CSS/JavaScript, без сборки.

## Локальный просмотр

Из папки проекта:

```sh
python -m http.server 8765 --bind 127.0.0.1
```

Открыть http://127.0.0.1:8765/.

## Файлы

- `index.html` — разметка, исходные стили, тексты и данные галерей в `#galleryData`.
- Стили и шрифты встроены прямо в `index.html` (так страница показывается быстрее); шрифты лежат в `assets/fonts/`.
- `site.js` — просмотр материалов кейсов и список документов. Исходные меню, анимации, лента рилсов, отзывы и плавающая запись находятся в `index.html`.
- `documents.js` — список реальных документов Word для скачивания.
- `assets/` — локальные обложки, материалы кейсов, отзывы и два видео.

Запись и социальная кнопка Telegram ведут напрямую в https://t.me/gridzakon. Статьи ведут в канал https://t.me/grid_zakon.

## Документы Word

Файлы Word клиент пока не предоставил. При получении положить их в `assets/documents/` и добавить записи в `documents.js`:

```js
window.GRIDZAKON_DOCUMENTS = [
  { title: 'Название документа', url: 'assets/documents/file.docx' }
];
```

Также поддерживаются общедоступные HTTPS-ссылки на Google Drive. Для локальных файлов используется скачивание; внешние открываются в новой вкладке. До добавления документов отображается сообщение о подготовке материалов, без неработающих кнопок.

## Весы (3D)

- `scales3d.js` — маленький загрузчик: подгружает сцену, когда блок рядом.
- `src/scene.js` — исходник сцены; `scene.min.js` — собранный файл (Three.js внутри, только нужные части).
- Пересборка после правок `src/scene.js` (нужен Node.js):

```sh
npm i three@0.160.0 esbuild@0.21.5
npx esbuild src/scene.js --bundle --minify --format=esm --outfile=scene.min.js
```

Затем поменять `?v=` у `scene.min.js` в `scales3d.js` и у `scales3d.js` в `index.html`.
- Материалы: HDRI `assets/3d/studio.hdr` (Poly Haven, ferndale_studio_11, CC0, уменьшен до 512 px), пластик `assets/3d/plastic_*` (ambientCG Plastic012A, CC0).
